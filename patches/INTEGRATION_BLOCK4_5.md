## Поведение

- **Горизонт.** Пресеты 7/14/30/60/90/180/365 + любой период через «Месяц ▾ → С даты / По дату».
  URL: `/calendar/grid?from=2026-10-01&to=2027-03-31` (`to` включительно, важнее `days`).
  366 дней — технический предел от `days=100000`, не продуктовый.
- **Мини-календарь.** Клик по месяцу: если его 1-е число уже загружено — плавная прокрутка,
  иначе переход на `from=YYYY-MM-01` с текущим горизонтом.
- **Боковые стрелки.** Прокручивают на ~80% видимой ширины; на краю диапазона подсвечиваются
  и грузят предыдущий/следующий период.
- **Клавиатура.** ← ↑ ↓ → по дням, Home/End — край строки, PageUp/PageDown — ±7 дней,
  Enter/Space — модалка действий.
- **Hover-строка.** Дата, объект/категория, «занято N из M: источники», цена. Заменяет `title`.
- **Конфликт.** Красная рамка, если день занят сверх `unit_count` и среди занимающих есть и
  ручная запись (блок без канала / бронь `data_source=MANUAL`), и внешняя (iCal-канал, RC).
  Только для сегодняшнего и будущих дней. В подзаголовке — кнопка «Конфликты: N дн.».

## Известные ограничения

- **Эхо площадки даст ложный конфликт.** Если площадка в своём фиде возвращает даты, которые
  сама импортировала из нашего экспорта, ручная бронь + её эхо выглядят как «ручная + iCal».
  Импорт эхо не фильтрует. Проверить на пилоте Суточно до блока 4.7 — иначе Telegram-алерты
  будут шуметь.
- **Двойной счёт ручной брони в iCal-экспорте.** `occupancyGrid` / `occupancyByDate` считают и
  `CalendarBlock`, и парный `Booking`. Для `unit_count = 1` не влияет; для мини-отеля категория
  закроется на площадках раньше времени. В шахматке исправлено (`occupancyDetails`), экспорт
  не трогал.
- Flash-атрибут `error` из `GridActionController` в `layout.html` не выводится (показывается
  только `success`) — ошибки модалки пользователь не видит. Было и до блока.
