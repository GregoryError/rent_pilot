# Цвета каналов в шахматке

Ветка: `feat/channels-mvp`. Миграция **V23** (`channels.color`). Зависимостей нет.

## Что входит

| Файл | Что изменилось |
|---|---|
| `db/migration/V23__channel_color.sql`, `entity/Channel.java` | цвет канала, `#RRGGBB` |
| `service/ChannelPalette.java` | палитра из 30 цветов, цвет по умолчанию, буква канала |
| `controller/ChannelController.java`, `settings/channels.html` | квадратик с буквой слева от названия канала → палитра → `POST /settings/channels/{id}/color` |
| `service/OccupancyGridService.java`, `fragments/occupancy-grid.html` | плитка занятого дня: цвет и буква канала; легенда со списком каналов |
| `static/css/core.css` | стили плиток, палитры |
| `test/.../ChannelPaletteTest.java` | контраст белого текста на каждом цвете, проверка значений |

## Поведение

- **Занят с площадки** — плитка цвета канала, на ней первая буква названия канала и цена, текст белый.
- **Закрыт вручную** (ручная бронь, ремонт, личное использование, hold из шахматки) — чёрная плитка,
  без буквы. Если на дне есть и ручная запись, и площадка, плитка чёрная (плюс красная рамка конфликта).
- **Свободен** — фон как раньше, текст обычного цвета темы: чёрный на светлой, светлый на тёмной.
- **Цвет не выбран** — канал получает цвет из палитры по своему id, так что шахматка цветная сразу.
- **Брони из RealtyCalendar** канала не имеют: серо-синяя плитка с буквой «R», в легенде появляется,
  только если такие дни есть на экране.
- **Мини-отель** (`unit_count > 1`): цвет получает только полностью занятый день, вместо буквы —
  счётчик занятых номеров; частично занятый день остаётся жёлтым.
- **Прошедшие занятые дни** приглушены.
- Произвольный цвет задать нельзя: сервер принимает только значения из палитры.

## Известные ограничения

- **Не проверено в браузере** — только компиляция и 111 unit-тестов. Смотреть: не наезжает ли
  буква на цену в узкой плитке (30px) и читается ли чёрная плитка на тёмной теме.
- **Канал страницы бронирования** в разделе «Каналы» скрыт, поэтому цвет ему выбрать нельзя —
  он остаётся автоматическим.
- Контраст белого текста на самых светлых цветах палитры (например `#0094B5`) — около 3.5:1:
  достаточно для жирной буквы, для мелкой цены на пределе.

## Доработки шахматки (следом)

Миграций нет.

- **Открытие на текущей дате с прошлым слева.** Если период не задан явно (`/calendar/grid`,
  кнопка «Сегодня», смена горизонта), слева подгружаются 30 прошедших дней, а сетка сразу
  прокручена к сегодняшнему дню. Назад — колесом, тачпадом или боковой стрелкой; на левом краю
  стрелка грузит предыдущий период, как раньше. Выбранный горизонт (160 дней и т.д.) считается
  от сегодня, прошлое идёт сверх него. После сохранения из модалки режим «от сегодня» сохраняется.
  Явный период (`from=…`, прыжок на месяц, ← →) работает как прежде, без прошлого слева.
- **Плитки ближе к квадрату за счёт высоты, а не ширины.** Ширина дня снова от 30px (плотность
  как была), высота строки — 32px вместо 44px. Колонка «Объект / категория» сужена до 190px и
  стала однострочной: у объекта с одной категорией — только название объекта, с несколькими —
  «Объект · Категория». Категория, число номеров и адрес — в подсказке при наведении.
- **Палитра:** +6 цветов, всего 30. Автоматический цвет каналов без выбранного цвета мог
  поменяться (изменился размер палитры).

Проверить: шахматка открывается на сегодня; прокрутка влево показывает прошлое; «Сегодня»
возвращает к текущей дате; после сохранения брони из модалки вид не прыгает в прошлое.

## Цвет по умолчанию и подсказка (V24)

- Цвет каналу выдаётся **случайно при создании** и сохраняется; по возможности не совпадает
  с цветами других каналов хоста. Миграция **V24** один раз раздаёт случайные цвета каналам,
  у которых цвет не выбран (на лету случайный цвет менялся бы при каждой загрузке шахматки).
- В «Каналах» рядом с цветным квадратом подпись «цвет ▾», над списком каналов — строка-подсказка,
  в самой палитре — заголовок «Цвет броней этого канала в шахматке».

Проверить: высота строки шахматки ~32px, буква и цена на плитке не наезжают друг на друга;
длинное название объекта обрезается многоточием, полное — в подсказке; у существующих каналов
после деплоя цвета стабильны между перезагрузками.
