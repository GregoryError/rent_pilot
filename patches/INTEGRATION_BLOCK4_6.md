## Поведение

### Шахматка
- **Удаление ручной записи.** Клик по дню → в модалке сверху блок «Ручные записи на этот день»
  с кнопкой «Удалить» (с подтверждением). Блок `calendar_blocks` удаляется физически, парная
  бронь получает `status = 'DELETED'` — перестаёт занимать даты и считаться в выручке.
  Импорт с площадок (`channel_id IS NOT NULL`) удалить нельзя: вернётся при следующей синхронизации.
- **160 дней по умолчанию**, пресет 180 заменён на 160.
- **Ширина.** `.main-content:has(.grid-shell)` снимает `max-width: 1200px` — на `/calendar/grid`
  и на главной. Остальные страницы не затронуты.
- Боковые стрелки скрываются, если сетка помещается без прокрутки.

### Главная (за выбранный месяц)
- **Прогноз выручки** = суммы броней, разложенные по ночам месяца, + оценка по плановой цене для
  занятых ночей без суммы (iCal-блоки, ручные брони без цены). Ремонт, личное использование,
  hold и нулевые закрытия из RC деньгами не считаются. Сверх `unit_count` выручка не начисляется.
- **Занятость** — занятые ночи / (ночи × `unit_count`), включая ремонт и закрытия.
- **Броней** — записи-продажи с заездом в этом месяце.
- **Потенциал** — свободные ночи от сегодня до конца месяца по текущим ценам хоста.
- **Потенциал оптимизации** — те же свободные ночи: цены хоста против
  `PricingEngine.calculateRecommendations`. Только для объектов с одной категорией на один номер.
  Ничего не пушит.
- **Выручка по дням** — прошлое заливкой, будущее пунктиром; оценочная часть — отдельным сегментом.
- Все расчётные цифры помечены `estimated`.
- Старый ряд KPI переехал ниже под заголовок «Факт по броням за месяц». Его «Доход» считает
  брони по дате заезда целиком, поэтому с «Прогнозом выручки» (по ночам) цифры могут не совпадать.

## Известные ограничения

- Счётчик «Броней» и оценка выручки зависят от того, отдаёт ли площадка эхо импортированных дат
  (см. INTEGRATION_BLOCK4_5). При `unit_count = 1` эхо ничего не удваивает — сверх вместимости
  записи не считаются. Для категорий с несколькими номерами эхо может дать лишнюю «бронь» и
  лишнюю оценочную ночь.
- Имя гостя из модалки сохраняется в `bookings.guest_name` как введено, без `PdAnonymizer`.
  В списке записей показывается только инициал. Было и до блока.
