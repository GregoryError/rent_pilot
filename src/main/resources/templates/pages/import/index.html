Импорт данных

Загрузка бронирований из XLS-экспорта RealtyCalendar

Загрузить XLS
Экспортируйте файл из RealtyCalendar → Статистика → Бронирования → Экспорт в XLS. Дубликаты автоматически пропускаются. Удалённые и отменённые брони не импортируются.
Очистка данных

Удалит все импортированные бронирования и автоматически созданные расходы на уборку для выбранного объекта. Данные пришедшие по вебхукам тоже будут удалены. Это действие необратимо.
