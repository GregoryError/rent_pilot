Удаление аккаунта

← Назад к пользователю

Ошибка

В аккаунте есть администратор — его нельзя удалить.

Будет удалено без возможности восстановить
  • Аккаунт
  • Объекты
  • Брони
  • Страницы
  • Площадки, настройки, онбординг, ссылки входа и сброса пароля

Публичные адреса — страницы бронирования, короткие ссылки с карточек, анкеты, расписание горничной и ссылки для площадок — станут отвечать «страница удалена» (410). В журнал попадёт запись «аккаунт удалён по запросу» с номером аккаунта и числами, без адресов и имён. Из бэкапов данные уйдут вместе с их сроком — 30 дней.

Если пользователь просил и копию данных — сначала сделайте выгрузку в карточке.
