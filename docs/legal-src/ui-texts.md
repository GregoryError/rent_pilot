# Тексты чекбоксов и подписей в интерфейсе OptiRent

Внутренний файл, не публикуется. Общие правила:
- чекбоксы **не отмечены заранее**;
- каждое согласие — отдельный чекбокс со ссылкой на отдельный документ (ч. 1 ст. 9 152-ФЗ в ред. 156-ФЗ);
- сохраняем: дату и время, версию документа (номер редакции), идентификатор субъекта (аккаунт или заявка);
- ссылки открываются в новой вкладке, форма при этом не сбрасывается.

## 1. Регистрация хоста

```
☐ Принимаю Пользовательское соглашение и ознакомлен с Политикой обработки персональных данных
      → «Пользовательское соглашение»  = /legal/terms
      → «Политикой обработки ПД»      = /legal/privacy
☐ Даю согласие на обработку персональных данных
      → «согласие»                    = /legal/consent
☐ Мне больше 18 лет  [можно объединить с первым чекбоксом]
[ Зарегистрироваться ]   — неактивна, пока не отмечены обязательные пункты
```

Записать: `terms_version`, `privacy_version`, `consent_version`, `accepted_at`.

## 2. Настройки публичной страницы хоста (распространение)

Рядом с каждым полем — переключатель «Показывать гостям»: имя, телефон, Telegram, WhatsApp, адрес объекта. По умолчанию — выключено.

Поле «Условия и запреты (необязательно)» — свободный текст, выводится внизу публичной страницы.

При сохранении, если включено хотя бы одно поле:
```
☐ Согласен на показ выбранных данных гостям — они станут видны всем, кто откроет страницу
      → «Согласен» = /legal/consent-public
```
Записать: перечень включённых полей, версию документа, время. Каждое изменение набора полей — новая запись.

## 3. Сведения об операторе для гостей (обязательно до включения формы брони)

Подпись к блоку:
> Для гостей вы — оператор их персональных данных. Эти сведения увидят гости в тексте согласия. Без них форма бронирования не включится.

Поля: ФИО или наименование (обязательно), ИНН (необязательно), контакт для обращений по персональным данным (обязательно), адрес [ПРОВЕРИТЬ: обязательно/нет — см. INTEGRATION.md].

## 4. Форма бронирования (страница и виджет хоста)

Поле «Имя» — подсказка: «Сохраним только первую букву».
Поле «Комментарий» — подсказка: «Не указывайте паспортные данные и другие лишние сведения».

```
☐ Даю согласие хосту {{host_name}} на обработку моих персональных данных для ответа на заявку. Мне больше 18 лет.
      → «согласие» = /legal/guest-consent/{{host_slug}}
[ Отправить заявку ]
Заявку получит хост {{host_name}}. Сервис OptiRent передаёт её по поручению хоста и не участвует в бронировании и оплате. Политика OptiRent
      → «Политика OptiRent» = /legal/privacy
```

Записать в заявку: `consent_at`, `guest_consent_version`.

## 5. Анкета отзыва

Над кнопкой:
```
Имя указывать не обязательно. Если укажете — сохраним только первую букву. Не пишите в отзыве телефоны, адреса и данные других людей.
Отзыв получит хост {{host_name}}. Подробнее
      → «Подробнее» = /legal/review
```
Только если у хоста включена публикация отзывов:
```
☐ Разрешаю опубликовать мой отзыв на странице хоста
[ Отправить ]
```

## 6. Баннер cookie

См. /legal/cookies, раздел «Текст баннера». Ссылки: «Подробнее о cookie» → /legal/cookies, «Согласие на Метрику» → /legal/cookie-consent. В подвале каждой страницы — «Настройки cookie».

## 7. Подвал сайта

```
Политика конфиденциальности · Пользовательское соглашение · Cookie · Настройки cookie
[ФИО], самозанятый, ИНН [ИНН] · [email]
```
Ссылки: /legal/privacy, /legal/terms, /legal/cookies.

## 8. Прочие подписи

**Добавление помощника (горничной):**
> Вы — оператор данных своего помощника. Внесите их, только если помощник согласен. Лучше указать подпись («Горничная»), а не полное имя. Никому не передавайте PIN, кроме помощника.

**Страница горничной (под формой PIN):**
> Страница расписания хоста {{host_name}}. Доступ — по PIN, который выдал хост. Ваши данные обрабатывает хост; OptiRent хранит их по его поручению. Политика OptiRent → /legal/privacy

**Подключение Telegram:**
> Уведомления придут в ваш Telegram. В них не будет данных гостей — только событие, даты и ссылка в кабинет. Отключить можно в любой момент в настройках.

**AI-чат помощника** (если есть) — над полем ввода:
> Не вводите сюда имена, телефоны и другие данные гостей и других людей.

**Удаление аккаунта:**
> Аккаунт и все данные (объекты, брони, заявки гостей, отзывы, помощники) будут удалены из базы в течение 30 дней, из резервных копий — до [ЗАПОЛНИТЬ] дней. Скачайте нужные данные заранее.
